## ✦ Brand Manifesto

**AETHER 925** redefines modern luxury silver jewelry. Rejecting fragile fast-fashion electroplating that wears thin in weeks, every single piece in this boutique is cast in certified **solid 925 sterling silver**, alloyed for structural heft, and finished with a mirror rhodium flash or deep artisanal oxidized patina.

- **100% Recycled Solid Sterling Silver**: Certified circular metallurgy.
- **Lost-Wax Casting**: Fluid, organic molten silhouettes paired with brutalist geometries.
- **Rhodium Protective Barrier**: Superior scratch resistance and platinum-grade cold shine.
- **Lifetime Assay Guarantee**: Official laser-engraved 925 purity hallmark on every item.

## ✨ Interactive Features & UI/UX

### 1. 🔍 Interactive Editorial Hero with Product Hotspots
- High-definition editorial model campaign with **pulsing interactive pin hotspots**.
- Hovering or tapping pins reveals instant preview cards for pieces worn directly on the model (Neck curb chain, Molten stacker, Brutalist signet) with direct quick-view access.

### 2. 💎 "Shop by Vibe" Curated Archives
- Four immersive aesthetic categories with smooth hover transformations and ambient glassmorphism:
  1. **Everyday Stackers** (Fluid molten ripples & bands)
  2. **Bold Oxidized** (Raw brutalist dark patina signets)
  3. **Chains & Pendants** (Architectural curb links & gothic thorn talismans)
  4. **Minimalist Silver** (Hollow-core tension ear cuffs & geometric hoops)

### 3. ⚡ Dynamic Product Filter & Multi-Criteria Sort
- Instant real-time filtering across categories: `All Drops (8)`, `Rings (2)`, `Chains (3)`, `Oxidized (2)`, and `Cuffs & Ear (1)`.
- Real-time sorting engine:
  - **Featured Drops**
  - **Price: Low to High**
  - **Price: High to Low**
  - **Highest Rated (5.0 ★)**

### 4. 👁️ Instant Quick-View Modal
- Deep inspection overlay with high-resolution imagery, full alloy specifications, weights, comfort-fit guidelines, and an **interactive ring & chain size selector** (`US 6` - `US 11`, `18"` - `24"`).
- Direct "Add to Bag" action without losing scroll position.

### 5. 🛍️ Slide-Out Cart Drawer with Live Shipping Meter
- Real-time slide-out bag with smooth backdrop blur.
- **Free Express Shipping Progress Meter**: Dynamic calculation toward complimentary insured shipping (Threshold: **$150.00**).
- Quantity adjusters (`+` / `−`), one-click item removal, and auto-updating financial breakdown.
- **Promo Code Engine**:
  - `SILVER15`: Unlocks 15% VIP inaugural order discount.
  - `VIP20`: Applies flat $20.00 studio voucher.
- 256-bit encrypted checkout simulation modal with detailed receipt alerts.

### 6. 💱 Live Multi-Currency Switcher
- Global currency selector in the top ticker bar supporting:
  - **USD ($)** — Base rate `1.0`
  - **EUR (€)** — European rate `0.92`
  - **GBP (£)** — British rate `0.79`
- Dynamically converts all prices, cart totals, and shipping thresholds on the fly.

### 7. ⌨️ Global Command-K Search Engine
- Press `⌘K` (Mac) or `Ctrl + K` (Windows) or tap the search icon to activate the modal.
- Live autocomplete searching across product titles, descriptions, categories, and aesthetic vibes.
- Quick-filter trending pill tags (`Signet`, `Stacker`, `Figaro`, `Ear Cuff`).

### 8. 📸 Community UGC Lookbook ("As Styled By You")
- Grid featuring authentic street-style editorial photography from global community members.
- Clicking any look opens a social modal displaying real-world wear, likes, location, and a direct **"Shop This Look"** button that targets the exact piece worn.

### 9. 📐 Specification Manuals & Sizing Charts
- US Ring Diameter & Circumference millimeter calibration chart.
- Chain drop length visual standards (18" collarbone, 20" daily drop, 22" layering drop).
- Solid 925 preservation guidelines (daily wear benefits, ultrasonic cleaning, and patina care).

## 🛠️ Technology Stack

- **Core**: Semantic HTML5 with accessibility landmark tags and ARIA attributes
- **Styling**: Pure Modern CSS (Vanilla CSS3) with custom properties (CSS variables), CSS Grid, Flexbox, glassmorphism filters, and fluid responsive typography
- **Typography**: Google Fonts — *Space Grotesk* (Architectural display) & *Inter* (Ergonomic body)
- **Logic**: Modern ECMAScript 6+ (Object state management, event delegation, dynamic DOM rendering)
- **Media**: High-resolution optimized JPEG/WebP photography and MP4 video walkthrough

## 🚀 Getting Started

To explore or run this project locally, clone the repository and launch any local static server:

```bash
# 1. Clone the repository
git clone https://github.com/Zohairhingoro/AETHER.git

# 2. Enter the directory
cd AETHER

# 3. Launch with Python (built-in)
python -m http.server 8080

# OR launch with Node.js
npx serve .
```

Open your browser and navigate to `http://localhost:8080`.

## 🤝 Two-Profile GitHub Collaboration & Achievements

This project was built through active pair programming and mentorship between **Zohair Hingoro** and **Zarmeen Hussain**. 

To display the repository on **both GitHub profiles**, connect contributions, and unlock official GitHub Achievement Badges (e.g. **Pair Extraordinaire**, **Pull Shark**, **Quickdraw**), follow this exact industry workflow:

### Step 1: Initialize Git and Co-Author the Launch Commit
Co-authoring gives commit credit and green contribution calendar graph squares to **both** developers simultaneously:

```bash
git init
git branch -M main
git add .

# Make a Co-Authored Commit
git commit -m "feat: launch AETHER 925 boutique solid sterling silver showcase

Co-authored-by: Zarmeen Hussain <zarmeenhussain05@gmail.com>
Co-authored-by: Zohair Hingoro <student1596270aptechii@gmail.com>"
```

> [!TIP]
> **GitHub Email Matching**: Both contributors must use their verified GitHub addresses (`zarmeenhussain05@gmail.com` and `student1596270aptechii@gmail.com`).

---

### Step 2: Push to the Primary Repository
One partner creates the GitHub repository (for example under `Zohairhingoro/AETHER` or `zarmeenhussain/AETHER`):

```bash
# Example: Adding remote and pushing
git remote add origin https://github.com/Zohairhingoro/AETHER.git
git push -u origin main
```

---

### Step 3: Add Collaborator Access
1. Open the repository on GitHub.
2. Go to **Settings** > **Collaborators** > **Add people**.
3. Search for the partner's username (`zarmeenhussain` or `Zohairhingoro`) and send the invitation.
4. The partner accepts the invitation via email or notification. Both developers now have direct commit and branch permissions!

---

### Step 4: Fork to Connect on Both Profiles
To show the repository directly in both profiles' repositories lists:
1. The invited partner clicks **Fork** on the top right of the repository.
2. The fork will be created at `https://github.com/zarmeenhussain/AETHER` with the subtitle:
   *`forked from Zohairhingoro/AETHER`*.
3. Pin the repository on your GitHub profile overview under **Customize your pins** so visitors on both profiles immediately see it as a featured project.

---

### Step 5: Unlocking the **Pair Extraordinaire** & **Pull Shark** Achievements 🏆
